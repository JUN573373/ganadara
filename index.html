세부 변환 설정 (합산 기준 · 부케 표기 · 배송문자)

합산 금액은 발주부케와 함께 엑셀에 표시됩니다. 본식은 예식일별 탭과 좌측 상단 날짜를 생성하고, 촬영은 한 시트로 출력합니다. 코멘트는 엑셀 특이사항에 함께 들어갑니다.

합산 및 정제 옵션

배송안내 문자 공통 템플릿

각 행의 ‘배송문자’ 버튼 → 아래 양식에 실제 데이터를 대입 → 수정 후 복사합니다. 자동 발송은 하지 않습니다.
사용 항목: {예식일자}, {신부명}, {발주부케}, {배송시간}, {배송지}, {배송일정}, {이상원코멘트}
배송일정은 배송시간 + 배송지입니다. 아웃 시간과 별개이며, 누락된 값은 확인필요로 표시됩니다.

부케 표기 변환 규칙 표

상품마다 위에서부터 적용합니다. 예: VS플러스 → VS+, BL- → $CODE(BL-03 유지). 여러 주문은 각각 변환한 뒤 함께 표시합니다.

원문 포함 단어 ➔ 최종 바꿀 표기 삭제

설정은 이 브라우저에 자동 저장됩니다. 변경 즉시 미리보기에 반영되며 직접 수정한 셀 값은 유지됩니다.
